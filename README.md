# 2026 电赛智能小车固件（循迹 + 平衡球）

基于 **STM32F103ZE**（Cortex-M3，72MHz）的竞赛小车固件，Keil MDK（ARMCC 5.06u7 / AC5）+ STM32 标准外设库 V3.5 开发。同时完成两套任务：

- **循迹**：8 路数字循迹传感器 → 循迹 PID + JY61P 陀螺仪阻尼 → TB6612 双电机差速
- **平衡球**：K230 视觉追踪球位 → 球 PID → 步进电机驱动平台俯仰，使球保持在目标位置

---

## 一、硬件组成

| 模块 | 型号/规格 | 连接接口 |
|---|---|---|
| 主控 | STM32F103ZE（512KB Flash / 64KB RAM） | — |
| 电机驱动 | TB6612 双 H 桥，12V 电机供电 | 见下表 |
| 循迹传感器 | 8 路数字循迹（I2C），黑线=0 | I2C2：SCL=PB10, SDA=PB11，地址 0x4C |
| 编码器 | 双路正交编码器 | 右：TIM3（PA6/PA7）；左：TIM4 重映射（PD12/PD13） |
| 陀螺仪 | 维特智能 JY61P（六轴，取 Z 角速度） | USART2：PA2=TX, PA3=RX，115200 / 100Hz |
| 步进电机 | 28BYJ 类（1.8°×32 细分 = 6400 脉冲/圈） | PB8=STEP, PB9=DIR，TIM6 中断发脉冲（2kHz） |
| OLED | SSD1306 128x64（8x16 字库，4 行×16 列） | 软件 I2C：PA4=SCL, PA5=SDA，地址 0x78 |
| 视觉模块 | 嘉楠 K230（NanoTracker 单目标追踪） | USART1：PA9=TX, PA10=RX，115200 |
| 按键 | 轻触按键 | PB0=模式切换（循环 02→03→04→05→06）、PB1=启动（GPIO 直读，上拉） |
| 调试接口 | SWD（JTAG 已禁用，释放 PB3/PB4/PB15） | — |

### TB6612 接线（以实际代码为准）

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| PWMA（左轮） | PA0 = TIM5_CH1 | 左电机 PWM |
| AIN1 / AIN2（左轮） | PA12 / PB12 | 方向 |
| PWMB（右轮） | PA11 = TIM1_CH4 | 右电机 PWM |
| BIN1 / BIN2（右轮） | PB13 / PB14 | 方向 |
| STBY | PB5 | 高电平使能（必须保持高，否则输出高阻滑行） |

PWM：ARR=999、预分频 72-1 → 1kHz，速度范围 **-999 ~ 999**（正=前进）。

> ⚠ 注意：根目录 `引脚定义表.txt` 中 OLED（PB6/PB7）与左电机 PWM（PA8/TIM1_CH1）为**旧版文档**，与实际代码不符——实际接线以本表为准（PB6/PB7 是死代码 IMU.c 的 I2C1）。

### 循迹传感器物理位置（mm，距中线）

| 传感器 | S0 | S1 | S2 | S3 | S4 | S5 | S6 | S7 |
|---|---|---|---|---|---|---|---|---|
| STM32 引脚 | PA5 | PA3 | PB3 | PA2 | PB1 | PA4 | PB4 | PA15 |
| 位置(mm) | -50 | -38 | -1 | -0.8 | 0.8 | 1 | 38 | 50 |

误差计算：检测到黑线的各路按位置加权求质心（`Tracking_GetError`）。

## 二、工作模式（PB0 循环切换，PB1 启动）

主循环 20ms 状态机：`WAIT → ACCEL（缓启）→ RUN → DECEL（缓停）→ BACK（后退）→ DONE`。

| 模式 | 功能 | 动作时序 | 停止条件 |
|---|---|---|---|
| **MODE_02** | 循迹 + 平衡球（基础模式） | 巡航 300，急启急停 | ≥4 路见黑线且运行 >17s → 停车 → **全速后退 100ms** → 完成 |
| **MODE_03** | 定点测试 | 球目标 +340 → 稳定（\|P−340\|≤40 持续 100ms）→ 目标 -340 → 稳定（≤50）→ 停车 | 自动，OLED 显示用时 |
| **MODE_04** | 循迹 5 秒停 | 巡航 300，缓启缓停（约 1.5s 斜坡） | 运行 ≥5s → 缓停 → 完成 |
| **MODE_05** | 循迹 + 终点识别 | 降速 20%（巡航 240）、缓启缓停、陀螺仪阻尼降为 1.8 | 两阶段终点检测（先连续 5 循环无黑线，再连续 5 循环 ≥3 路黑线）→ **延长循迹 3s** → 缓停 |
| **MODE_06** | 循迹同 05 + 编码器调球目标 | WAIT 时左轮编码器增量实时累加球目标（±12cm） | 同 MODE_05；**球目标 ≤ -4cm 时自动切换特调球 PID**（1.0/0.25/0.20） |

**所有模式**的公共保护：循迹读取失败（`g_lt_raw==0xFF`）连续 5 个循环 → 立即停车进入 DONE；平衡球 PID 全程持续工作（DONE 阶段也保持调球）。

### 球目标换算（MODE_06）

- 编码器增量 → cm：`ball_target += 左轮编码器增量 × TARGET_K(0.02)`，限幅 ±12cm
- cm → PID 目标：`setpoint = 74 × cm − 30`（实测标定：+5cm→340，+7cm→490，+10cm→710）

## 三、控制算法与参数

### 循迹 PID（TrackPID，位置式，积分分离）

| 参数 | 值 | 说明 |
|---|---|---|
| TRACK_KP | 40.0 | 小误差温和修正；大误差进入输出饱和由差速限幅主导 |
| TRACK_KI | 0.3 | 积分，**分离阈值 \|e\| ≤ 15** 才积分，积分限幅 ±80 |
| 差速限幅 | ±120 | DIFF_MAX/DIFF_MIN |
| 输出限幅 | ±1000 | 与 PWM 分辨率一致（双级限幅） |
| 陀螺仪阻尼 | 5.0（M05/06 用 1.8） | `diff = -PID输出 - 阻尼×ωz`（JY61P 顺时针为正，取反构成抑制） |

左轮 = 巡航 + 差速，右轮 = 巡航 − 差速；差速取反修正电机位序（注释保留说明）。

### 球平衡 PID（vendored PID-Library，20ms 采样）

| 参数 | 值 | 说明 |
|---|---|---|
| KP / KI / KD | 1.2 / 0.25 / 0.35 | P-on-Error，正向 |
| 输出限幅 | ±800 步（±45°） | 步进目标，映射到机械行程 |
| MODE_06 特调 | 1.0 / 0.25 / 0.20 | 球目标 ≤ -4cm 时实时切换（含调节阶段与运行中） |

### 速度/斜坡

| 项目 | 值 |
|---|---|
| 巡航速度 | 300（M05/06 降速 20% → 240） |
| 缓启缓停斜坡 | step=4（M04）/ 3（M05/06），约 1.5s；其余模式 step=80（急加速） |

## 五、构建方法

1. Keil MDK uVision5（ARMCC V5.06 update 7，AC5），设备选择 **STM32F103ZE**（Keil.STM32F1xx_DFP 2.4.1）
2. C/C++ Defines：`USE_STDPERIPH_DRIVER`
   - ⚠ `STM32F10X_HD` **未出现在 Defines 中**（高密度器件宏），若编译报错请手动添加
3. Include 路径：`.\Start; .\Library; .\User; .\System; .\Hardware`
4. 编译输出：`Objects\Project.axf`（当前未生成 hex）
5. 调试：SWD（JTAG 已被代码禁用）；`RTE` 中 DBGMCU_CR=0x7 保证调试暂停时外设时钟不断

## 六、K230 视觉脚本（K230/08.nanotracker-1.0guche.py）

- 功能：**单目标实时追踪**（NanoTracker/SiamRPN 架构），非分类检测——追踪初始框内的任意目标
- 三模型（存于 K230 的 /sdcard/kmodel/）：模板裁剪 127×127、特征主干 255×255、追踪头（阈值 0.05）
- 初始化：固定 20s 模板初始化阶段（每秒 1 帧），随后自由追踪
- 追踪区域（ROI）：x∈[60,1220]，y∈[415,545]（1280×960 图像）；目标面积 >10000px² 或出界时保持上一帧有效框
- 与 STM32 通信（115200）：
  - 每帧发送 **YbProtocol 数据包**（框坐标，板级 SDK 格式）
  - 每帧发送 **ASCII 位置**：目标中心 x 从 ROI 映射到 **±1000**（中线=0），格式 `"%d\r\n"`——STM32 的 UART.c 解析此格式

## 八、系统时钟与中断

- **72MHz 主频**，主循环 20ms（`Delay_ms(20)`）
- **TIM2 → 1ms 中断**：递增全局 `g_elapsed_ms`（球 PID 时间源、JY61P 新鲜度、模式计时）
- 中断优先级（Group 2，全部主优先级 0）：TIM2(子0) > USART1 球位(子1) > TIM6 步进(子2)；USART2 JY61P 主优先级 1

## 九、已知事项

- `Hardware/IMU.c`（ICM20948）为**死代码**：主程序已改用 JY61P 串口陀螺仪，模块保留作参考/回退
- `Hardware/Key.c` / `LED.c` 为**预留模块**，未接入主程序（模式/启动键由 main 直读 GPIO 实现）
- `stm32f10x_it.h` 中 `TIM4_IRQHandler` 仅声明未定义（TIM4 用作编码器计数，未开中断）
- IMU.c 存在已知比例 bug（±2000dps 配置 vs 65.5 灵敏度），注释已标明（gulaoshi 原样）
- 代码注释中保留了大量**历史调参记录**（KP/DIFF/传感器位置组等），供后续回退参考
- 电机停止为**滑行**（仅清 PWM，方向引脚保持），如需主动刹车需另行拉高方向引脚
